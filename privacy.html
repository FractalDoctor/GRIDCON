⚡ GRIDCON — PRIVACY POLICY

Last updated: March 2026

DATA COLLECTION

GRIDCON does not collect, store, or transmit any personal data. The app does not require an account, login, or any form of registration.

NETWORK REQUESTS

GRIDCON makes direct HTTPS requests to the following publicly available services to retrieve electricity grid data:

EirGrid Smart Grid Dashboard
• smartgriddashboard.com — grid frequency, demand, generation, wind, CO₂, SNSP, and interconnector data
• vargen.smartgriddashboard.com — solar generation data

These requests contain no user-identifying information. No API keys, tokens, or credentials are transmitted. The data returned is publicly available statistical information about the Irish electricity grid.

LOCAL DATA STORAGE

GRIDCON caches grid data locally on your device to provide instant display on launch. This cache contains only electricity grid statistics (frequency, demand, generation values) and is stored in the app's sandboxed cache directory. User preferences (region selection, colour theme) are stored locally using UserDefaults. No data is stored in iCloud or shared with other apps.

ANALYTICS AND TRACKING

GRIDCON does not include any analytics frameworks, crash reporting services, advertising SDKs, or tracking mechanisms of any kind. The app contains no third-party code that collects user data.

THIRD-PARTY SERVICES

The only external services contacted are the EirGrid endpoints listed above. No data is sent to any third party for any purpose.

CHILDREN'S PRIVACY

GRIDCON does not collect personal information from anyone, including children under the age of 13.

CHANGES TO THIS POLICY

If this privacy policy changes, the updated version will be posted at this URL. The app itself will not change its data practices without a corresponding update to this policy.

CONTACT

For questions about this privacy policy or the app, please open an issue on GitHub.
