⚡ GRIDCON

Real-time Irish electricity grid monitor

GRIDCON pulls live data from the EirGrid Smart Grid Dashboard and presents it through a retro CRT terminal interface inspired by Cold War-era control rooms. Every number is real. Every trace is live.

FEATURES

  • Live grid frequency with oscilloscope display
  • System demand and generation with 24-hour traces
  • Wind and solar generation tracking
  • Interconnector power flow monitoring with animated map
  • CO₂ intensity and SNSP stability metrics
  • All-Island, Republic of Ireland, or Northern Ireland filtering
  • Green phosphor and amber phosphor colour themes
  • CRT visual effects — scanlines, glow, phosphor bloom
  • No account required. No ads. No tracking.

DATA SOURCE

All data is sourced from the EirGrid Smart Grid Dashboard, a publicly available service provided by EirGrid for transparency. Grid metrics update every 5 minutes; frequency updates every 15 seconds.
